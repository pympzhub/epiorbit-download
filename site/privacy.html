Privacidade / Privacy

Versão 1.0 · Última atualização / Last updated: 2026-11-07

PT — Privacidade

O EpiOrbit é uma aplicação Windows que guarda localmente no perfil do utilizador as listas, o progresso de visualização, as definições e as chaves de API configuradas. Não exige uma conta EpiOrbit nem disponibiliza sincronização em servidor próprio na versão 1.0.

A aplicação consulta serviços externos para pesquisa, metadados, horários, imagens e classificações, incluindo TMDB, TVmaze e, opcionalmente, OMDb. Os pedidos podem revelar a esses serviços o endereço IP, as consultas efetuadas e dados técnicos de ligação; cada serviço rege-se pela sua política de privacidade. Os recursos visuais usados pela interface podem carregar de fornecedores externos, incluindo Google Fonts, cdnjs, Tailwind CDN e imagens remotas, quando disponíveis. As credenciais individuais são fornecidas pelo utilizador e usadas para autenticar os pedidos aos respetivos fornecedores.

Os dados locais continuam disponíveis até serem apagados pelo utilizador ou por operações de manutenção. A desinstalação normal poderá preservar a pasta de dados. Para eliminar os dados pessoais, o utilizador deve usar os mecanismos de limpeza da aplicação ou remover os dados do seu perfil Windows, depois de guardar eventuais cópias de segurança.

Esta página descreve o funcionamento conhecido da versão 1.0 e deve ser revista se a arquitetura de dados mudar. Para questões ou problemas, utiliza o canal de suporte público, sem publicar chaves API ou dados sensíveis.

EN — Privacy

EpiOrbit is a Windows app that stores lists, viewing history, settings and configured API credentials locally in the user's Windows profile. Version 1.0 does not require an EpiOrbit account or offer synchronization through an EpiOrbit-hosted service.

The app contacts external services to retrieve search results, metadata, schedules, imagery and ratings, including TMDB, TVmaze and optionally OMDb. Requests can disclose an IP address, search terms and connection metadata to these providers; their own privacy policies apply. Interface resources may also load from third-party hosts including Google Fonts, cdnjs, Tailwind CDN and remote image providers. Users supply their own API credentials, which are used for corresponding provider requests.

Locally stored data remains until deleted by the user or by a maintenance operation. Normal uninstallation may preserve the user's data folder. To remove it, users can use the app's data tools or remove its profile data after backing up anything they wish to keep.

This notice reflects the known version 1.0 behavior and should be reviewed if the app's data practices change. For support, use the issue tracker; never publish API keys or sensitive personal data.
