# EpiOrbit 1.1 — Backlog inicial

**Objetivo:** evoluir após estabilização do lançamento público 1.0, sem quebrar os dados existentes.

## Prioridade alta
- Empacotar CSS, fontes e outros recursos usados em runtime para melhorar privacidade e funcionamento offline.
- Centralizar completamente as traduções PT/EN, incluindo mensagens de erro e notificações.
- Aperfeiçoar recomendação por géneros, temas e adaptações com maior transparência e avaliação.
- Melhorar o diagnóstico e os relatórios de falhas sem recolha de dados pessoais por defeito.
- Testes automatizados de regressão para os filtros, listas, calendário e atualização sem perda de dados.

## Prioridade média
- Mostrar estado de sincronização e avisos sobre datas de estreia incertas.
- Personalização adicional do calendário, vista trimestral e exportação para formatos de calendário quando tecnicamente viável.
- Mais filtros para gêneros, lançamento, país e plataformas.
- Melhor gestão de backups entre computadores com passos claros e opcionais.

## Processo sugerido
1. Publicar 1.0 e recolher feedback através de Issues.
2. Consolidar bugs reais por frequência e impacto.
3. Criar versão 1.1.0-beta para testes na VM.
4. Validar atualização 1.0 → 1.1 com backups antes de distribuir.
